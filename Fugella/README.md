## 🌟 About

FUGELLA is a sophisticated e-commerce platform inspired by luxury fashion retailers like Zara and Net-a-Porter. Built with clean, semantic HTML, modern CSS, and vanilla JavaScript, this project showcases a seamless shopping experience for curated pre-loved designer fashion.

**Key Features:**
- 🎨 Minimalist, editorial-inspired design
- 💎 Premium typography and spacing
- 📱 Fully responsive across all devices
- ✨ Smooth animations and transitions
- ❤️ Interactive wishlist functionality
- 🔍 Search and filtering capabilities
- 🛒 Modern e-commerce UI/UX patterns

- **JavaScript (ES6+)** - Vanilla JS, no frameworks
- **Design Inspiration** - Zara, Net-a-Porter, The Row

## ✨ Features Breakdown

### User Interface
- Clean, Zara-inspired aesthetic
- Sticky navigation with smooth scrolling
- Category browsing with hover effects
- Product cards with image zoom on hover
- Newsletter subscription with validation

### Interactive Elements
- Wishlist toggle (hearts) with local state
- Smooth scroll-to-section navigation
- Custom notification system
- Scroll-triggered fade-in animations
- Responsive design (mobile, tablet, desktop)

### Performance
- Optimized images from Unsplash
- CSS Grid for efficient layouts
- Intersection Observer for scroll animations
- Minimal JavaScript for fast load times

## 🎯 Getting Started

1. **Clone the repository**
```bash
   git clone https://github.com/YOUR-USERNAME/fugella.git
```

2. **Open the project**
```bash
   cd fugella
```

3. **Launch the site**
   - Simply open `index.html` in your browser
   - Or use Live Server in VS Code for auto-reload

## 💻 Local Development

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- A code editor (VS Code recommended)
- Optional: Live Server extension for VS Code

### Running Locally
```bash
# Option 1: Double-click index.html

# Option 2: Use Python's built-in server
python -m http.server 8000

# Option 3: Use VS Code Live Server
Right-click index.html → Open with Live Server
```
